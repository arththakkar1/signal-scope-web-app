# Evaluation Metrics

## Primary Metric
- **ROC-AUC**: Evaluated on the held-out set and the unseen-generator split. The unseen-generator AUC carries the highest weight and is the main tie-breaker.

## Additional Required Metrics
- **Macro-F1**: To evaluate balanced classification performance.
- **Confusion Matrix**: To show True Positives, False Positives, etc.
- **Accuracy and FPR**: Evaluated at the chosen operating threshold.

## Scoring Breakdown
- AI/ML Implementation: 25%
- Technical Implementation: 20%
- Innovation & Creativity: 15%
- Explanation & Trust Impact: 15%
- User Experience: 10%
- Problem Understanding: 10%
- Presentation & Demo: 5%
